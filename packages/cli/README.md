# jawdrop

Copy jawdrop effects into your project.

```sh
npx jawdrop add scramble-text magnetic
npx jawdrop list
```

It detects React or Astro from your `package.json` and writes the files to `src/components/jawdrop/`. Options: `--flavour react|astro|vanilla`, `--dir <path>`, `--force`.

32 text, background, scroll and cursor effects, no dependencies, all under 4 KB. See them live at https://whosdrix.github.io/jawdrop and read more at https://github.com/whosdrix/jawdrop.
